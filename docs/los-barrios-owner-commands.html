LOS BARRIOS

Справочник команд владельца Telegram-бота

Telegram ID владельца должен находиться в ADMIN_TELEGRAM_IDS в файле .env. Команда /admin показывает краткую справку внутри бота.

Основные команды

/start

Регистрация или возврат в главное меню.

/myid

Показать свой Telegram ID.

/help

Общая справка.

/admin

Команды организатора.

/players

Игроки, количество Policía и рейтинг.

/profile

Персонаж, Dinero, Respeto и статусы.

/ranking

Общий рейтинг Respeto.

/barrios

Рейтинг по barrios.

/dictionary / /dict

Испанско-русский словарь.

/events

Активные события для игрока.

Misiones

/mission                    Текущая misión
/missions                   Доступные misiones
/missionlist                Полный список для организатора

Создание и редактирование

/missionadd ID | ISO_DATE | TITLE | DESCRIPTION | LOCATION
/missionedit ID | ISO_DATE | TITLE | DESCRIPTION | LOCATION
/missiontime ID | YYYY-MM-DD | HH:MM
/missionvocab ID | SPANISH | RUSSIAN
/missionexample ID | EXAMPLE

Пример:

/missionadd intro | 2026-09-20T18:00:00+03:00 | La presentación | Познакомьтесь с игроками | Главный зал
/missiontime intro | 2026-09-20 | 18:30
/missionvocab intro | ¿Cómo te llamas? | Как тебя зовут?

Управление миссией

/missionstart ID
/missionfinish ID
/missiondelete ID
/missionjoin ID
/missionleave ID

/missionfinish, /missionjoin и /missionleave без ID используют активную misión.

Игроки и статусы

/money NICKNAME AMOUNT
/respeto NICKNAME AMOUNT
/wanted NICKNAME LEVEL
/penalty NICKNAME | DESCRIPTION
/clearpenalties NICKNAME
/police NICKNAME
  • /money и /respeto принимают положительные и отрицательные значения.
  • /wanted устанавливает уровень розыска от 0 до 3.
  • /police переключает игрока между обычной ролью и Policía.

Лидеры barrios

/leader BARRIO_ID | NICKNAME
/leaderremove BARRIO_ID

Пример: /leader nomadas | El Tigre

ID barrios: nomadas, navegantes, lumieres, fuegos, panteras.

Mercado

/market
/shoplist
/shopadd ID | NAME | PRICE | STOCK/all | DESCRIPTION
/shopedit ID | NAME | PRICE | STOCK/all | DESCRIPTION
/shopdelete ID
/buy ID

Пример: /shopadd llave | Llave | 300 | 5 | Открывает одну дверь

Игровые события

/eventlist
/eventpreset rata | TARGET
/eventpreset robo | TARGET
/eventpreset guerra | TARGET
/eventadd ID | TYPE | TITLE | DESCRIPTION | TARGET
/eventedit ID | TYPE | TITLE | DESCRIPTION | TARGET
/eventstart ID
/eventfinish ID
/eventdelete ID

Типы: la_rata, robo, guerra, custom.

Цели: all, police, nickname, ID barrio или список через запятую.

Территории и карта

/map
/territories
/win BARRIO_ID
/territoryremove BARRIO_ID
/territoryremove ZONE_NUMBER
  • /win nomadas выдаёт barrio новую территорию.
  • /territoryremove nomadas убирает случайную территорию barrio.
  • /territoryremove 5 освобождает конкретную зону.

Изображения

/leaderphoto BARRIO_ID
/mapphoto

После команды отправьте нужное изображение как фотографию в Telegram.

Удаление персонажа

/restart 0000

Удаляет профиль, Dinero, Respeto, инвентарь, участие в misiones и статус лидера. После удаления используйте /start.

Код настраивается переменной CHARACTER_RESET_CODE в .env.
